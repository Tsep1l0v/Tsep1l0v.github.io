Политика конфиденциальности

Дата вступления в силу: 1 января 2026 г.

Настоящая Политика конфиденциальности описывает, как сервис MangaLove (далее — «Сервис»), включая мобильные приложения и веб-сайт, собирает, использует, хранит и защищает информацию пользователей. Используя Сервис, вы подтверждаете, что ознакомились с настоящей Политикой и согласны с её условиями.

1. АДМИНИСТРАТОР ДАННЫХ

Администрация Сервиса является оператором персональных данных. По вопросам обработки данных обращайтесь: support@mangalove.ru.

2. КАКИЕ ДАННЫЕ МЫ СОБИРАЕМ

2.1. Данные, предоставляемые пользователем при регистрации:

  • адрес электронной почты (email);
  • никнейм (отображаемое имя);
  • имя пользователя (уникальный логин);
  • пароль (хранится в зашифрованном виде).

2.2. Данные профиля, хранимые на сервере:

  • аватарка (загруженная пользователем);
  • обложка профиля;
  • описание профиля;
  • статус чтения и настройки аккаунта.

2.3. Данные активности, хранимые на сервере:

  • закладки (списки тайтлов с тегами и заметками);
  • история чтения и прогресс по главам;
  • статистика (количество прочитанных тайтлов и глав, время чтения);
  • карточки (виртуальные коллекционные карточки);
  • колоды карточек;
  • комментарии и отзывы;
  • внутренняя валюта (сердца) и история транзакций.

2.4. Технические данные, собираемые автоматически:

  • IP-адрес;
  • тип и модель устройства;
  • версия операционной системы;
  • версия Приложения;
  • язык устройства.

3. КАК МЫ ИСПОЛЬЗУЕМ ДАННЫЕ

  • 3.1. Для регистрации и авторизации пользователя в Сервисе.
  • 3.2. Для обеспечения работы функционала: сохранение закладок, отслеживание прогресса чтения, отображение статистики.
  • 3.3. Для хранения коллекции карточек, колод и связанных данных.
  • 3.4. Для обработки комментарии и обратной связи.
  • 3.5. Для технической поддержки и улучшения работы Сервиса.
  • 3.6. Для предотвращения мошенничества и нарушений условий использования.

4. ХРАНЕНИЕ ДАННЫХ

  • 4.1. Персональные данные и данные аккаунта хранятся на серверах Администрации.
  • 4.2. Данные хранятся в течение всего срока существования аккаунта пользователя.
  • 4.3. При удалении аккаунта персональные данные удаляются с серверов в течение 30 дней.
  • 4.4. Некоторые данные (настройки, скачанные главы для офлайн-чтения) хранятся локально на устройстве пользователя.

5. ПЕРЕДАЧА ДАННЫХ ТРЕТЬИМ ЛИЦАМ

  • 5.1. Мы не продаём и не передаём персональные данные пользователей третьим лицам.
  • 5.2. Сервис использует открытый API MangaDex (https://api.mangadex.org) для получения контента. Запросы к API MangaDex могут содержать технические данные (IP-адрес, тип устройства).
  • 5.3. Данные могут быть раскрыты по требованию компетентных государственных органов в соответствии с действующим законодательством.

6. ЗАЩИТА ДАННЫХ

  • 6.1. Все соединения с серверами осуществляются по защищённому протоколу HTTPS.
  • 6.2. Пароли хранятся в хешированном виде и не доступны Администрации в открытом виде.
  • 6.3. Применяются современные методы шифрования для защиты данных при передаче и хранении.
  • 6.4. Доступ к персональным данным ограничен уполномоченными сотрудниками.

7. ПРАВА ПОЛЬЗОВАТЕЛЯ

  • 7.1. Право на доступ: вы можете запросить информацию о данных, хранящихся на вашем аккаунте.
  • 7.2. Право на исправление: вы можете изменить данные профиля (никнейм, аватар, описание) в настройках Сервиса.
  • 7.3. Право на удаление: вы можете удалить свой аккаунт через настройки Сервиса или обратившись в поддержку.
  • 7.4. Право на экспорт: вы можете запросить копию ваших данных, обратившись в поддержку.
  • 7.5. Для реализации прав обращайтесь: support@mangalove.ru.

8. КОНФИДЕНЦИАЛЬНОСТЬ ДЕТЕЙ

  • 8.1. Сервис не предназначен для лиц младше 13 лет.
  • 8.2. Мы сознательно не собираем персональные данные детей младше 13 лет.
  • 8.3. Если вы являетесь родителем или опекуном и узнали, что ваш ребёнок предоставил нам персональные данные, свяжитесь с нами для их удаления.

9. COOKIE И АНАЛИТИКА

  • 9.1. Мобильные приложения не используют файлы cookie.
  • 9.2. Веб-сайт использует файлы cookie для обеспечения работы сервиса, сохранения настроек и аутентификации. Вы можете управлять настройками cookie в браузере.
  • 9.3. Сервис может использовать инструменты аналитики для сбора обезличенных данных об использовании (сбои, производительность). Эти данные не содержат персональной информации.

10. ИЗМЕНЕНИЯ ПОЛИТИКИ КОНФИДЕНЦИАЛЬНОСТИ

  • 10.1. Администрация вправе вносить изменения в настоящую Политику.
  • 10.2. О существенных изменениях пользователи будут уведомлены через Сервис.
  • 10.3. Продолжение использования Сервиса после внесения изменений означает принятие обновлённой Политики.

11. КОНТАКТНАЯ ИНФОРМАЦИЯ

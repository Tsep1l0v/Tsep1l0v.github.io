Privacy Policy

Effective Date: January 1, 2026

This Privacy Policy describes how the MangaLove service (the "Service"), including mobile applications and the website, collects, uses, stores, and protects user information. By using the Service, you acknowledge that you have read and agree to this Policy.

1. Data Controller

The Service Administration acts as the personal data operator. For data inquiries, contact: support@mangalove.ru.

2. What Data We Collect

2.1. Data provided during registration: email, display name, username, password (hashed).

2.2. Profile data: avatar, cover image, description, reading status and settings.

2.3. Activity data: bookmarks, reading history, progress, statistics, cards, decks, comments, in-app currency and transaction history.

2.4. Technical data: IP address, device type/model, OS version, App version, device language.

3. How We Use Data

For registration/authentication; core functionality (bookmarks, progress, statistics); card collection; comment processing; support and improvement; fraud prevention.

4. Data Storage

Data is stored on Administration servers for the account lifetime. Deleted within 30 days after account deletion. Some data (settings, offline chapters) stored locally.

5. Third-Party Data Sharing

We do not sell or transfer personal data. Service uses public MangaDex API; requests may include technical data. Disclosure possible if required by law.

6. Data Protection

HTTPS, hashed passwords, modern encryption, restricted access.

7. User Rights

Access, rectification, erasure, portability. Contact support@mangalove.ru.

8. Children's Privacy

Not intended for under 13. We don't knowingly collect children's data. Contact us for removal.

9. Cookies and Analytics

Mobile apps: no cookies. Website uses cookies for functionality. Analytics collects anonymized data.

10. Changes to This Policy

We may update this Policy. Significant changes will be notified. Continued use means acceptance.

11. Contact Information

Email: support@mangalove.ru
